# Rumars Solution Remote Support

Брендированная сборка открытого клиента RustDesk 1.4.9 для Windows x64.

**Скачивать приложение следует только после успешного завершения GitHub Actions.**
Это реальная сборка оригинального клиента, а не загрузчик оригинального EXE.

В главном окне: фирменный логотип, телефон +375 (29) 743-01-51, сайт https://rumars.pro.

## Как получить EXE

1. Открыть раздел **Actions** в этом репозитории.
2. Найти **Build Rumars Support (Windows x64)**, выбрать успешный запуск.
3. В разделе Artifacts загрузить **Rumars-Support-Windows-x64**.
4. В ZIP находится `Rumars-Support.exe`.

Portable-режим и встроенная кнопка установки сохраняются из официального RustDesk. Публичные серверы RustDesk остаются по умолчанию. Не включаются скрытая установка и незаметный постоянный доступ.

## Исходники

Workflow извлекает RustDesk из тега `1.4.9`, применяет `brand/apply.py`, компилирует Flutter/Rust и собирает self-extracting Windows EXE через оригинальный `libs/portable/generate.py`.

## Лицензия

Основа RustDesk лицензируется на условиях AGPL-3.0. При распространении клиентам необходимо выполнять обязательства этой лицензии, включая предоставление соответствующего полного исходного кода (RustDesk 1.4.9 и изменения брендинга), сохранение уведомлений и указание изменений. Не удаляйте сведения об исходном авторе и лицензии из соответствующих файлов.

Не подписанная сертификатом сборка может вызывать предупреждение Windows SmartScreen. До распространения необходима реальная проверка Windows 10/11: переносный запуск, ID, пароль, соединение, установка через UI, UAC, служба, удаление.
